# Ember
Windows desktop utility for people running independent coding agents. Its primary job is to prevent system sleep during confirmed agent work or an explicit manual hold. The display follows the separate display setting. Supported agents: Claude Code, Codex, OpenCode, Pi, Oh My Pi, Antigravity and Cline. Hooks provide session state; process CPU activity is an estimate. Battery guards and reversible lid-close overrides protect the machine. Closing may keep the utility in the tray. Default window is 1100 by 700; remember normal geometry and maximization. Keep the established light/dark palette and use the supplied folded ember artwork throughout. Prioritize quick status checks and compact controls over presentation.
